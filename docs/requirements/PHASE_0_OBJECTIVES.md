# Phase 0 — Foundation Objectives

1. Establish Ubuntu Server 24.04 LTS as the dedicated FRIDAY host.
2. Establish two private GitHub repositories.
3. Archive the v0.2 baseline without losing historical files.
4. Establish secure Git practices and secret exclusion.
5. Establish reproducible Python environment and test execution.
6. Establish server logging, time synchronization, resource monitoring and backup procedures.
7. Establish repository governance and phase sign-off process.

## Exit criteria
- OS verified
- SSH administration verified
- Git/GitHub authentication verified
- Core repository initialized
- Data repository initialized
- Baseline archived and tagged
- Tests pass
- Secrets excluded
- Documentation complete
- Backup/recovery procedure tested
- User signs off Phase 0
