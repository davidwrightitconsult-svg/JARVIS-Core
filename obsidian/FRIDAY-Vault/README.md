# FRIDAY Obsidian Vault — moved

Since Phase 4 the knowledge vault lives in its own private repository,
**`FRIDAY-Knowledge-Vault`** (cloned on jarvis020 at
`~/friday/FRIDAY-Knowledge-Vault`). See `docs/architecture/PHASE_4_KNOWLEDGE.md`.

Create or check it with:

    python -m friday.knowledge init  --vault ~/friday/FRIDAY-Knowledge-Vault
    python -m friday.knowledge check --vault ~/friday/FRIDAY-Knowledge-Vault
